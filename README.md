# Traffic Demand Prediction Hackathon

## Approach
1. Data preprocessing and cleaning
2. Timestamp feature extraction
3. Geohash-based location processing
4. Categorical feature encoding
5. CatBoost Regressor training
6. 5-Fold Cross Validation
7. Prediction generation

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- CatBoost

## Output
`submission.csv` with columns:
- `Index`
- `demand`
